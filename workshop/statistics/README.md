# Statistics

- **bayesian_psi_analysis.ipynb**: This notebook walks the advanced user through an applied example of using hierarchical Bayesian modeling to infer the underlying distribution of true 3D spin-orbit obliquities for exoplanets given the measured 2D distribution and some basic assumptions.
- **mc_statistics.ipynb**: This intermediate notebook covers Monte Carlo (MC) statistical methods applied to analyzing exoplanet populations via the NASA Exoplanet Archive, specifically to determine whether gaseous or rocky worlds are statistically more "water-like" in their bulk densities.
- **statistics_basics.ipynb**: This beginner-friendly notebook provides a hands-on introduction to basic statistical concepts such as the Gaussian distribution, random draws, and the Law of Large Numbers.
