# Machine Learning

- **lstmae_stars_demo.ipynb**: This advanced notebook showcases an example of unsupervised learning in an astrophysical context, using the `TensorFlow` package to train a Long-Short Term Memory Autoencoder to detect anomalous stars in large surveys.
- **machine_learning_exercise.ipynb**: This tutorial describes how to use the `PyTorch` package to build a convolutional neural network that can identify hand-written numbers.
