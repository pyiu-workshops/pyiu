# Advanced Plotting

- **advanced_plotting_complete.ipynb**: Introduction to Matplotlib, followed by detailed discussion of plot formatting options, including subplot arrangement, tick formatting, and color bars.
- **plotting_supernova_demo.ipynb**: Demonstrates basic plotting techniques using a supernova light curve as an astrophysical example, then highlights several customization features that Matplotlib offers.
